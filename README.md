# Next.js Video Chat with ZEGOCLOUD

Build a fully functional video chat app using Next.js and ZEGOCLOUD Call Kit.

## Features
- Video conferencing with ZEGOCLOUD.
- Easily integrate with your own Next.js projects.
- 10,000 free minutes for new users.

## Requirements
- Node.js 16+ and npm installed.
- A free account on [ZEGOCLOUD](https://www.zegocloud.com).
